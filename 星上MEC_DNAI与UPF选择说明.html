1. 基本概念：DNAI、UPF 与 DN

DNAI 标识 DN（Data Network）的用户面接入点；UPF 是实现用户面转发、连接 5GC 与 DN 的网络功能。DNAI 与 UPF 密切相关，但两者不是同一个标识。

概念含义
DN数据网络，例如 Internet、企业专网或 MEC 网络。
UPF负责用户面转发，将 5GC 与 DN 连接起来。
DNAI标识用户面接入 DN 的位置；不是 UPF ID，也不是 UPF 接口地址。
UE用户设备
→ N3 →
UPF用户面转发

DN / MECDNAI 标识接入位置

不同 UPF 可能连接不同位置的 DN。例如，星上 UPF 可通过 N6 连接本卫星上的 MEC 网络，地面 UPF 则连接地面 MEC 网络。SMF 会结合业务需要、DNAI、网络策略和拓扑等信息选择合适的 UPF。

2. 推荐的管理需求表述

原句将“DNAI”和“SMF 的 UPF 选择信息”并列，容易被理解为两套互不相关的信息。DNAI 关联关系本身可以属于 SMF 的 UPF 选择信息。

网管需管理星上 MEC 组件的部署和配置，并配置 5GC SMF 所需的 UPF 选择信息（包括 DNAI 与 DN、星上 UPF 及 MEC 服务位置之间的关联关系）以及流量引导策略，使 SMF 能够选择适当的星上 UPF，并将符合策略的业务流量引导至星上 MEC。

这样表述的分工

  • 网管：提供相关配置、部署信息和策略。
  • SMF：根据会话、策略及网络配置执行 UPF 选择。
  • UPF：按 SMF 下发的转发规则实际转发匹配的业务流量。
如果只需简短描述，也可写：网管配置星上 MEC 部署信息、SMF 所需的 UPF 选择信息及流量引导策略，使 SMF 能够选择适当的星上 UPF，并将符合策略的业务流量引导至星上 MEC。

4. DNAI 关联信息与 UPF 选择信息的关系

两者不是完全相同的信息，但有交集和包含关系。

  • DNAI 及关联信息：描述目标 DN 接入点、能够连接该 DN 的 UPF，以及对应 MEC 服务位置。
  • SMF 的 UPF 选择信息：更广泛的信息集合，可包括 DNAI 及相关映射，也可包括 UPF 部署位置、能力、负载和可用性等。

5. 整体关系与转发流程

网管配置 DNAI 映射、UPF 选择信息、引导策略及 MEC 部署
→
5GC SMF根据会话、策略和网络配置选择 UPF
→ N4
星上 UPF执行用户面转发规则
→ N6
星上 DN / MEC处理业务流量
  1. 网管维护 MEC 应用部署及相关网络配置。
  2. SMF 根据 UE 会话请求、网络配置、策略及 UPF 可用性选择合适 UPF。
  3. SMF 通过 N4 向 UPF 下发用户面规则。
  4. UPF 按规则将匹配流量经 N6 转发到 DNAI 所标识的 DN 接入位置，抵达星上 MEC。

6. 标准化边界

以上参数表是便于理解的管理信息示例，不代表所有字段都已在 SA5 NRM 中定义为规范属性。

将这段内容作为 TR 28.874 §5.4.2 管理需求的归纳时，不应据此推断该 TR 已完整规定 DNAI 与 UPF、MEC 之间的 NRM 关联模型。标准化时仍需逐项核对现有 IOC 和属性，判断哪些可以复用，哪些构成管理模型缺口。

建议保留的参数类别：

  • DNAI 及其与星上 UPF、MEC 服务位置的关联信息；
  • SMF 用于选择星上 UPF 的相关信息，例如 UPF 部署位置、卫星标识及可用性；
  • 流量引导策略，例如业务流匹配条件、目标 DNAI 和引导动作；
  • MEC 组件的部署位置、服务地址及部署配置。
