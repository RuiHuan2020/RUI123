Rel-17：先确认“卫星接入会给 5G 管理带来什么变化”
FS_5GSAT_MO 研究卫星组件加入 5G 后的管理架构、场景和用例。它先搭起通用框架：卫星在网络里扮演什么角色，哪些管理问题需要研究。

Rel-18：发现 IoT NTN 有自己的一组问题
NB-IoT 和 LTE-M 终端更关注省电、覆盖不连续等问题，不能只照搬通用卫星管理研究，于是 FS_IoT_NTN 专门研究这些需求。这一步是从通用框架深入到特定终端和场景。

Rel-18：把已选定的研究结论写进规范
OAM_NTN 将部分研究成果转成管理能力、需求和信息模型。也就是说，管理系统开始有规范定义的内容可依照；但这不表示前面研究过的所有方案都被采用。

Rel-19 Phase 2：网络形态更复杂，管理对象和问题随之扩展
当卫星不仅转发信号，还可能在星上运行 gNB 或核心网功能，并且星地链路可能断续，就必须继续处理星上功能的管理、星地连接、移动性和存储转发。Phase 2 一边研究这些问题，一边把选定方案继续写进规范。

Rel-20 Phase 3：转向具体业务和跨网络协同
在已有管理能力的基础上，继续处理 GEO IoT NTN 上的 IMS 语音等具体业务，以及终端从地面网切换到 NTN 时需要的协同信息。
